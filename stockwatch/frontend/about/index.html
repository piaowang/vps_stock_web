关于 StockWatch

StockWatch 是一个可直接部署到 Nginx 的纯前端金融信息站点样板。

当前版本包含 5 个路径，目标是“开箱可见 + 易扩展”。

  • 首页：指数与个股卡片，支持图表弹窗与资讯入口。
  • 市场总览：市场情绪、板块热度、成交概况。
  • 股票列表：核心标的清单，便于后续接实时 API。
  • 财经新闻：静态新闻摘要，可换成真实源。
  • 关于页面：项目定位、部署说明、扩展方向。

下一步可扩展

  • 接入你自己的后端 API 以避免浏览器 CORS 限制。
  • 增加搜索、自选股、排序筛选和多语言支持。
  • 补充免责声明、数据来源和更新时间标记。
