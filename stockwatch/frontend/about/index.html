关于 StockWatch

StockWatch 是一个可直接部署到 Nginx 的金融行情站点。

首页展示全球主要市场总览，其他页面提供股票列表与资讯入口。

  • 总览：中/日/韩/美主要指数实时快照。
  • 股票列表：核心标的清单，接入后端实时 API。
  • 财经新闻：静态新闻摘要，可换成真实源。
  • 关于：项目定位、部署说明、扩展方向。

技术栈

  • 前端：静态 HTML / CSS / JS，由宿主机 Nginx 托管。
  • 后端：Node.js 聚合服务，Docker 部署，提供 REST 与 WebSocket。
  • 部署：GitHub Actions 自动同步到 VPS。
